# MyDesk v1 计划

> 署名：M&J Group · 473276@qq.com。基于 RustDesk（AGPL-3.0），修改后的源码按 AGPL 提供。

## 目标与验收链路

运维人员登录 MyDesk 客户端 → 看到自己有权限的全部设备 → 点击“连接”，无需输入 ID 和密码即进入远程控制；被控端员工始终看得到“谁在连接”并可断开；全程有审计日志。

## 架构

| 部分 | 形态 | 说明 |
| --- | --- | --- |
| mydesk-server | 单文件 Rust 程序 | 官方 hbbs（信令）+ hbbr（中继）+ 账号 API + 内嵌 Web 后台 + 自带 HTTPS，数据为 SQLite 单文件 |
| mydesk 客户端 | fork rustdesk/rustdesk | 内置服务器地址/公钥/API；新界面：被控端 + 运维端；强制升级 |

## 平台

| 平台 | 被控端 | 运维端 | 说明 |
| --- | --- | --- | --- |
| Windows | ✅ | ✅ | 服务方式无人值守 |
| macOS | ✅ | ✅ | 需 Apple 开发者签名+公证，员工需授权屏幕录制/辅助功能 |
| Android | ✅ | ✅ | 需授权屏幕录制与无障碍，重启后可能需再次确认 |
| iOS | ❌ | ✅ | 系统限制，不能被控 |
